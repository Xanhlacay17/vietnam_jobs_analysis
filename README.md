## 📌 Project Overview
This project builds an data cleaning using **Python** and **pandas** to process a raw dataset of job advertisements in Vietnam. The primary objective is to transform inconsistent, noisy text and tabular data into a structured, analysis-ready format for Analytics.

## 📊 Dataset Description
- **Source:** [Kaggle - Vietnam Jobs Dataset (by Nguyen Chi Tinh)](https://www.kaggle.com/datasets/nguyenchitinh/vietnam-jobs-dataset/data)
- **Size:** ~85,000 rows (job postings) across 1 core CSV file (~3 MB)
- **Data Period:** Market insights updated as of April 2025

## 🚀 Technologies Used
- **Language:** Python 3
- **Core Library:** pandas (Data Manipulation), NumPy (Mathematical & Array Operations)
- **Environment:** Google Colab
